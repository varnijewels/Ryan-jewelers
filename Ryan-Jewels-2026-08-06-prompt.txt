## 5. BLOCKERS AND EXTERNAL DEPENDENCIES

### Production email OTP configuration

Real email delivery requires these private server environment variables:

  CHECKOUT_OTP_SECRET
  SMTP_HOST
  SMTP_PORT
  SMTP_SECURE
  SMTP_USER
  SMTP_PASS
  SMTP_FROM

Do not expose these as PUBLIC_ environment values. Use an email account/app
password or a production transactional email provider before deployment.

### SMS OTP

SMS OTP with the Ryan Jewels sender name/logo was intentionally deferred after
choosing email OTP first. Branded SMS requires an SMS provider, sender-ID or
template registration and provider credentials. A logo cannot be guaranteed in
normal SMS notifications; that depends on the messaging channel/provider.

### Backend metal images

Metal selection can only display a different image when the backend product
variant contains the correct metal value and matching media. If an admin product
has no Yellow Gold/Rose Gold variant image mapping, the frontend must keep the
available product image rather than hardcode a fake one.

### Full checkout validation

The UI/design stage was intentionally prioritized. A complete authenticated
checkout test with a real cart, real saved addresses, live email SMTP, payment
method and final order placement still needs to be run after the remaining
checkout/account designs are finished.

### Existing repository diagnostics

Targeted checks for the latest Ryan files pass. The repository-wide Svelte check
still has older unrelated diagnostics. Do not treat every existing diagnostic as
being caused by the latest account/order work; isolate errors by changed file.

### Uncommitted work

The working tree contains many modified and new files from the current Ryan
Jewelers implementation. Do not run `git reset --hard`, checkout the files or
delete untracked Ryan assets. Review and commit the work before another broad
refactor.
