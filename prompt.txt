## 3. HARD RULES (from CLAUDE.md)

- Only SvelteKit + Svelte 5 runes + existing components + shadcn + Tailwind.
- Reuse existing components; never create a new one where an existing one fits.
- Section-by-section fidelity: exact order, copy, casing, icons, borders, font
  weights, spacing, radius, shadows, hover states. No "close enough".
- Container/spacing are computed contract values. NO guessed clamp().
- Fonts are exact requirements. Do not substitute lookalikes.
- Icons: use the exported Figma asset, not a generic lucide swap.
- LIVE COMMERCE DATA COMES FROM THE API ONLY. Never hardcode products, prices,
  stock, ratings or variant options. If the API omits a field, omit the element.
- Theme-owned static copy lives in the theme layer, never inline in a route.
- Preserve accessibility: aria-*, labels, semantic tags, focus, form links.
- Async/click buttons must show a loading indicator while in flight.
- Never touch lockfiles.
- Build order: micro components -> reusable -> layout -> sections -> page.

## 4. LAYOUT MODEL (decided 2026-07-31 - do not regress this)

The 1920 header artboard (186:56688) settles it:

  - outer gutters are FIXED px straight from the frame (61 for most sections)
  - there is NO `max-width` cap on any section container
  - the content box just grows; at 1920 it measures 1798 = 1920 - 61 - 61
  - inner column splits are PERCENTAGES of the content box, so rows keep the
    frame's proportions instead of one column eating all the extra width
  - fixed-size children keep their source box only where the source scrolls
    them; elsewhere they are a share of the row
